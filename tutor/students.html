What has to exist before this page can show learners

1
Connect Supabase
Add your project URL and anon key to assets/js/supabase-config.js, then run schema.sql.
2
A student–tutor link table
A table recording which tutor may see which student, with row-level security so tutors only read their own cohort.
3
Guardian consent capture
Verifiable parental consent for every learner under 18, as the Kenya Data Protection Act 2019 requires.
4
Matching and booking
A way for a student to request a tutor and for that request to be accepted.
